## 🚀 Deployment

This website is deployed using Cloudflare Pages.

To deploy your own copy:

1. Fork or clone this repository.
2. Open the Cloudflare dashboard.
3. Navigate to **Workers & Pages**.
4. Create a new Pages project and connect your GitHub repository.
5. Select **None** as the framework preset.
6. Leave the build command empty.
7. Set the build output directory to the repository root.
8. Deploy your website.

## 🔒 Security

- No backend or database is required.
- No form submissions or visitor data collection are implemented.
- Security headers are configured through Cloudflare Pages.
- No API keys, passwords, or private credentials should be committed.
