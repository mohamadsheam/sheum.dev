## Deployment

The portfolio is deployed using Cloudflare Pages.

To deploy the website:

1. Fork or clone this repository.
2. Open the Cloudflare dashboard.
3. Navigate to **Workers & Pages**.
4. Create a Pages project and connect your GitHub repository.
5. Select **None** as the framework preset.
6. Leave the build command empty.
7. Set the build output directory to the repository root.
8. Deploy the project.

Cloudflare Pages can automatically deploy subsequent changes pushed
to the connected GitHub repository.

## Security

- The website is designed to operate without a backend or database.
- No visitor data collection or form submissions are implemented.
- Security headers are configured through Cloudflare Pages.
- No API keys, passwords, or private credentials should be committed.
- Review personal information in publicly accessible files before publishing.
